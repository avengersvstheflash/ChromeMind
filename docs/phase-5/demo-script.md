# ChromeMind portfolio demo script

## 60–90 second sequence

1. Open a documentation page and launch ChromeMind.
2. Show the status indicating Chrome-managed/on-device processing.
3. Summarize the page and point out provider/privacy metadata.
4. Open a sensitive-looking login or payment page and show extraction refusal.
5. Open Settings and show Chrome on-device-only, Chrome-first, and cloud-only policies.
6. Enable activity insights and visit two development/research domains.
7. Open ChromeMind again and show the explainable local recommendation.
8. Dismiss the recommendation and open the activity controls.
9. Delete local activity data and show the empty state.
10. End on the README architecture/data-flow diagram.

## Recording rules

- Do not show real API keys, private browsing history, account data, or personal domains.
- Use a clean Chrome profile or synthetic demo domains where possible.
- Make cloud fallback explicit in the narration.
- State that Chrome controls Gemini Nano availability and preparation.
